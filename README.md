# Livemore Bio release values

This repository holds only release pages. Each release lists the values for one Livemore Bio version:
- the distribution commit;
- the SHA-256 of the installer;
- the SHA-256 of the release archive.

The same values are published on [livemorebiosciences.com](https://livemorebiosciences.com), whose account is separate from this one. Check either before you install. If the two disagree, or a download does not match, do not install: contact Livemore Biosciences.

The software itself is distributed from [MannyAmah/livemorebio-dist](https://github.com/MannyAmah/livemorebio-dist). Its installation guide shows how to check the values.
